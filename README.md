# 游戏优化助手

一个给 Windows 玩家的**只读**游戏性能诊断小工具：先说清楚你的电脑和游戏到底卡在哪，再给你一份**先预演、能一键还原**的优化脚本。

> A read-only Windows gaming performance assistant for Chinese players: it diagnoses first, then hands you a preview-only, fully reversible optimization script. No installer, no telemetry, no registry roulette.

它不装任何东西、不联网、不改游戏文件、不碰反作弊；也不会关掉你的杀毒软件、不会关 Windows 更新、不会批量禁用系统服务。所有采集都在本机完成，报告和数据只留在你自己的文件夹里。

## 三种用法

**1. 静态体检（`1-开始体检.bat`）**

只读扫一遍硬件、驱动、电源计划、显示器刷新率、后台程序占用和你的游戏设置，出一份报告：瓶颈在哪、哪些是脚本能代劳的开关、哪些只能你自己动手。

**2. 边玩边记录（`2-边玩边记录.bat`）**

陪你真打一把游戏，全程只读记录 CPU、显卡、显存、内存、磁盘、网络，以及后台都有谁在抢资源。卡了一下按回车留个标记，报告里会带时间戳记下来。打完生成一份实测报告，外加按实测结果挑出来的补充优化脚本。

**3. 开游戏前整备（`4-开游戏前整备.bat`）**

进游戏之前跑一下：暂停网盘同步、关掉抢内存和抢磁盘的后台大户，游戏退出后自动把它们放回来。默认也是只预演，停过什么都有记录。它就是按实测报告里查到的元凶排的优先级——网盘同步、聊天软件、覆盖层，再顺手做一次内存体检。

三个模式都守同一条规矩：**先看，不动手**。优化脚本默认只预演（把计划打印出来，什么都不改），你确认之后才执行；每改一项，都先把原值写进 `optimize-logs\journal.json`，随时能一键还原。

## 和「一键优化大师」的区别

| | 本工具 | 常见的一键优化 |
|---|---|---|
| 默认行为 | 只读，先预演 | 直接改，改了什么不告诉你 |
| 改动记录 | 每项都记原值，可一键回滚 | 通常没有回滚 |
| 关杀毒 / 关更新 | 明确不做 | 常见 |
| 批量禁用系统服务 | 明确不做 | 常见 |
| 安装第三方软件 | 不装 | 常捆绑 |
| 报告 | 完整的 Markdown 报告，可以转发给别人看 | 一句「已优化 3000 项」 |
| 联网 | 全程不联网 | 常有遥测 |

## 快速开始

1. 到 Releases 页面下载 `游戏优化助手.zip`（不想看源码就直接用这个）。
2. **把整个文件夹解压出来**（不要只解压里面单个文件），放桌面、D 盘都行，路径带中文也没关系。
3. 双击 `1-开始体检.bat`，跟着提示走，十来个问题、一两分钟。
4. 想更准，再双击 `2-边玩边记录.bat`，真打一把，回来读实测报告。
5. 以后每次准备打游戏，先双击 `4-开游戏前整备.bat`：它把抢内存的后台清掉，你打完它自己收尾。

需要管理员权限的只有「真正应用优化」这一步，脚本会自己弹 UAC 提示。

## 它永远不会做的事

- 关闭 Windows Defender / 实时保护
- 关闭 Windows 更新
- 批量禁用系统服务、改系统策略
- 删除或修改游戏文件、拦截反作弊进程
- 改显卡 BIOS、超频、加压
- 安装任何第三方软件或驱动
- 上传任何数据（全部留在本机）

有安全代价的项（关闭 VBS / 内存完整性）放在 `Risky` 之后，必须显式加 `-AllowRisky` 才会执行，报告里也会单独写明代价。

## 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1809 或更高 / Windows 11（64 位） |
| PowerShell | 5.1，系统自带，不用装 |
| 权限 | 体检和记录不需要管理员；应用优化时点一次 UAC |
| 其他 | 不安装、不联网、不注册 |

ARM 版 Windows 和精简版系统没有实测过。系统里 `Get-Counter` 计数器被裁掉的话，部分性能数据会显示为空。

## 报告里有什么

体检报告（Markdown）包含：

- 硬件与系统概览：CPU、显卡、内存、磁盘、分辨率与刷新率、系统版本、驱动日期
- 关键开关状态：电源计划、游戏模式、Game DVR、硬件加速 GPU 计划、显卡首选项
- 后台占用排行：谁在吃 CPU、内存和磁盘
- 瓶颈判断：显卡 / CPU / 内存 / 磁盘 / 驱动 / 电源 / 温度 / 网络，逐项给出结论和依据
- 分档清单：脚本能直接改的、建议你手动做的（BIOS、散热、驱动）、以及不建议碰的
- 每项改动都附「改完会怎样」，值不值得由你判断

边玩边记录的报告会额外给出整场游戏的时间线（CPU、显卡、显存、内存、磁盘、网络）、卡顿次数与最差帧时间，以及当时后台占用最高的进程排行。

## 反作弊与安全

游戏工具最容易被误伤的地方是反作弊，所以边界说清楚：

- 不注入游戏进程、不读写游戏内存、不挂钩图形接口
- 不动游戏文件、存档、驱动和内核
- 改动都落在当前用户的注册表项（HKCU）和用户级计划任务里，随时可回滚
- 不联网上传任何数据，报告只写在你自己的文件夹里

它做的事都发生在系统层面（电源计划、后台进程、GPU 首选项），通常在反作弊眼里和玩家自己关掉几个后台程序没有区别。但每个游戏的判定策略不同，任何第三方工具的风险请自行评估；竞技比赛期间建议只跑体检，不跑优化。

## 已知限制

- 精确 FPS 读不到。不注入游戏进程就拿不到帧数，记录模式用帧时间抖动和 CPU 侧负载间接反映卡顿，够用来找瓶颈，但不会给你一个「平均 143 FPS」的数字
- 温度依赖主板 WMI 支持，部分主板和笔记本读不到
- 混合输出（核显加独显、画面由核显输出）的笔记本，显卡占用可能偏低
- 独占全屏加 HDR 时，部分计数器采样间隔会变长
- 应用优化会结束你选中的后台进程，未保存的工作可能丢失，执行前先存档

## 源码结构与自行构建

```
work\src\GameOptimize.ps1          主程序：参数、采集、问诊、诊断、报告生成
work\src\GameOptimize.extra.ps1    优化脚本模板、改动清单、回滚逻辑
work\src\GameOptimize.monitor.ps1  边玩边记录：逐秒采样、时间线、实测报告
work\src\GameOptimize.extra2.ps1   找游戏、生成 bat 入口、主流程
work\assets\使用说明.txt           放进压缩包给使用者的说明
work\build.ps1                     拼接、语法自检、打包
docs\                              维护、发布与贡献说明
outputs\                           构建产物，已被 .gitignore 忽略
```

构建：

```
powershell -ExecutionPolicy Bypass -File .\work\build.ps1
```

产物是 `outputs\游戏优化助手\` 和 `outputs\游戏优化助手.zip`。仓库里不放构建产物，正式压缩包从 Releases 页面下载。
